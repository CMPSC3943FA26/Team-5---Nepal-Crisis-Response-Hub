# Nepal Crisis Response Hub - MVP Plan

## Product Goal

Nepal Crisis Response Hub will provide a centralized platform where people affected by emergencies in Nepal can access reliable crisis information, request assistance, and locate important emergency resources.

## Core MVP Features

1. View Crisis Alerts
2. View Emergency Contacts
3. Access Safety Guidance
4. Create an Account
5. Secure Login
6. Submit a Help Request
7. Set Request Urgency
8. Find Emergency Resources
9. Track Help Requests
10. Publish Verified Alerts

## Primary Users

- Affected residents
- Volunteers and responders
- Relief organizations
- Administrators
- Community members

## MVP Success Criteria

The MVP should allow a user to:

- Access emergency information
- Locate useful emergency resources
- Submit a request for assistance
- Indicate how urgent the request is
- Track the status of the request
- View alerts published by authorized administrators

## Future Features

Features outside the initial MVP may include:

- Donation coordination
- Missing-person reporting
- Family reconnection
- Geographic mapping
- Push notifications
- Nepali-language support
- Advanced volunteer coordination
