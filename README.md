# Nepal Crisis Response Hub

Nepal Crisis Response Hub is a web-based emergency response platform designed to help people in Nepal during disasters such as earthquakes, floods, landslides, fires, and other emergencies.

The system aims to connect affected residents with emergency information, resources, volunteers, responders, and relief services through one centralized platform.

## Product Scope

Nepal Crisis Response Hub is designed to provide:

- Verified crisis and emergency alerts
- Emergency contact information
- Disaster safety guidance
- Emergency help requests
- Help request urgency levels
- Nearby emergency resources
- Help request status tracking
- Volunteer and responder coordination
- Relief and recovery information
- Community support during disasters

## Planned Features

### Crisis Alerts

- View active emergency alerts
- View emergency severity and location
- Access important safety information
- Publish verified crisis alerts

### Emergency Assistance

- Submit an emergency help request
- Describe the emergency
- Select an urgency level
- Track the status of a request

### Emergency Resources

- View emergency contacts
- Find shelters and relief centers
- Locate food, water, and medical resources
- Access disaster safety instructions

### User Accounts

- Create an account
- Securely log in
- Manage account information
- View previous help requests

### Volunteer and Responder Support

- View emergency assistance requests
- Identify high-priority requests
- Coordinate volunteers and responders
- Update help request status

## Minimum Viable Product (MVP)

The initial MVP will focus on essential crisis-response functions:

1. View Crisis Alerts
2. View Emergency Contacts
3. Access Safety Guidance
4. Create an Account
5. Secure Login
6. Submit a Help Request
7. Set Request Urgency
8. Find Emergency Resources
9. Track Help Requests
10. Publish Verified Alerts

## Target Users

### Affected Residents

People impacted by disasters who need emergency information, resources, or assistance.

### Volunteers and Responders

People assisting affected communities and responding to emergency requests.

### Relief Organizations

Organizations coordinating disaster assistance, resources, and recovery efforts.

### Community Members

People seeking disaster information and community recovery resources.
